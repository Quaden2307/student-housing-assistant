| 2026-11-03 | A sweep that hits a network-level fetch failure returns partial stats (`fetch_failed`) instead of raising; the daily run continues to the next category, then makes one bounded retry pass over categories that fetch-failed or saw zero listings (page cap, stuck pagination and under-90-percent are answered-page anomalies, never retried), behind a 300 awake-second `wait_for_network`.
